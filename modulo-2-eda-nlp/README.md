# Módulo 2 — NLP y EDA de AG News

Segunda pre-entrega de Data Science III - Coderhouse.

## Objetivo
Preprocesar y analizar un corpus de 8.000 noticias
de AG News utilizando Python y SpaCy.

## Contenido
- Limpieza y lematización de texto.
- Análisis de longitudes y percentil 95.
- Frecuencias, bigramas y trigramas.
- Distribución de las cuatro categorías.
- Pruebas automáticas e informe PDF.

## Ejecución
Instalar las dependencias de requirements.txt
y el modelo en_core_web_sm de SpaCy.

Colocar ag_news_train.csv en data/ y ejecutar:

python preprocess_eda.py

## Resultados
- 7 pruebas aprobadas.
- Percentil 95: 31 tokens.
- Cuatro clases balanceadas.
- Test reservado para evaluación.
